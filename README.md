# DNA Explorer – גנטיקה: מהמולקולה לרפואה

אתר לימודי אינטראקטיבי בגנטיקה לתלמידי תיכון (מגמת מדעי הרפואה), בעברית מלאה.

## יחידות הלימוד
1. מבנה ושכפול DNA
2. שעתוק RNA והבדלים בין חומצות הגרעין
3. תרגום לחלבונים
4. מוטציות והשלכות מחלתיות
5. שיבוט והיסטוריה (הכבשה דולי)
6. הנדסה גנטית, CRISPR והיבטים אתיים

בכל יחידה: רקע עיוני, סיכום מושגים, איור SVG, סימולציה אינטראקטיבית ו-10 שאלות תרגול עם משוב מיידי.

## הפעלה
כל האתר נמצא בקובץ אחד – `index.html`. פותחים אותו בדפדפן (נדרש חיבור לאינטרנט לטעינת Tailwind והגופן).
